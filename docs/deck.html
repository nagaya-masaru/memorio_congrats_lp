WHY VOICEなぜ、声なのか

残しておきたいのは、記録ではなく、
その人の声に宿る想い。

写真や動画は、今や簡単に残せる時代。けれど、声や話した想いは、記録して残さなければいつかそっと消えてしまいます。声には、その人の温度や感情、その瞬間の空気まで宿っています。MemoriOは、かけがえのない声をカタチにして残し、人生の節目に贈り、何度でも聴き返せる宝物として届けます。

Value 01 想いまで、贈る。 声に込められた想いも一緒に届けることで、心に残る特別なギフトになります。
Value 02 離れていても、そばに。 どこにいても、大切な声がそっと寄り添い、つながりを感じられます。
Value 03 人生と一緒に、積み重なる。 声の記録が人生の節目ごとに増えていき、かけがえのない思い出が重なっていきます。

HOW IT WORKS使い方

声を集めて、開くだけ。

アプリが必要なのは、声を贈る側（購入者）だけです。受け取る側は蓋を開けるだけ、録音リンクの受け手はブラウザ録音で、どちらもダウンロードは不要です。

01 問いに答えて録音する 「今だから言える言葉は？」という問いから始まるので、録音ボタンの前で固まりません。
02 リンクで家族や友人からも集める LINEやメールで共有。受け取った人はアプリ不要で、ブラウザからそのまま録音できます。
03 蓋を開けるだけで、声が流れる スマートフォンを探す必要はありません。棚に置いた本体を開くだけで声に出会えます。
NO APP REQUIRED 祖父母への贈り物でも、操作を覚えていただく必要はありません。蓋を開ける ─ それだけが受け取る側の操作です。
