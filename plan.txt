この資料について
本資料は、既存の事業構想を起点に、壁打ちを通じて再定義・確定したMemoriOのブランド思想、ターゲット、体験設計、Customer Journey、タッチポイントを一つにまとめたブランド戦略ドキュメントです。
初期案で中心だった「人生の節目に寄り添い、家族の歴史を未来へつなぐ」という思想を残しつつ、現在のプロダクト形状に合わせて「声のメモリーブロック」「物理とデジタルの両方で人生と共に積み上がる」ブランドへ発展させています。

1. Brand Core
ブランド定義
MemoriO — 人生と共に積み上がる、声のかたち。
MemoriOは、人生の節目に生まれる大切な声を、ひとつずつ形にして残し、物理とデジタルの両方で積み重ねていくブランドです。声を単なる音声データとして保存するのではなく、誰かに贈り、受け継ぎ、未来の人生を支える「声の記憶」へ変えていきます。
ブランドが目指す文化
「声を贈る」ことを、人生の節目に自然に選ばれる新しい文化にする。
出産、誕生日、記念日、卒業、結婚、家族の節目。人生に生まれる声を“残すもの”から“贈るもの”へ変え、時間と距離を越えて受け継いでいきます。
2. ブランドコンセプトとメインメッセージ
メインメッセージ
人はずっと昔から、声で想いを伝えてきました。喜びも、祈りも、愛情も、励ましも、別れも。文字よりも先に、声は人と人をつなぐものであり、誰かの存在そのものを感じさせるものでした。
声には、その人の感情や温度、その瞬間の空気まで宿っています。だからこそ、ふと耳にしたひと言が誰かを笑顔にしたり、節目の喜びを深く噛み締めさせたり、立ち上がる力を与えたりすることがあります。
遠く離れていても、声を聞けば距離が少し縮まる。苦しい時も、大切な人の声が心の支えになる。そして、時間が経つほど、その声はかけがえのない記憶へと変わっていきます。
MemoriOは、そんな人生の中で生まれる大切な声を、ひとつずつ形として残していくブランドです。
生まれた日の産声。初めて名前を呼んだ声。誕生日に贈られた言葉。背中を押してくれたひと言。離れて暮らす家族からのメッセージ。
人生の節目ごとに声を残し、ひとつずつ積み重ねていく。その積み重なりは、やがて一人の人生となり、家族の歴史になっていきます。
MemoriOが残したいのは、ただの音声データではありません。誰かを喜ばせ、誰かを勇気づけ、人生の大切な瞬間を何度でも思い出させてくれる「声の記憶」です。
人生と共に積み上がる、声のかたち。
コンセプトメッセージ（100〜200字）
声には、その人の温度や感情、過ごした時間まで宿っています。MemoriOは、人生の節目に生まれる大切な声をひとつずつ残し、積み重ねていくブランドです。喜びも、励ましも、遠く離れた誰かへの想いも、未来の自分や家族を支える「声の記憶」として形にしていきます。

4. Product Philosophy
4.1 声のメモリーブロック
MemoriOのキューブ型は、単なる造形ではなく「人生は記憶の積み重ねでできている」というブランド思想を物理化したものです。1つの人生の節目に1つのキューブを残し、節目が増えるほどリアルのキューブもデジタル上の記憶も積み上がります。
4.2 物理 × デジタルの二重構造
構造
役割
物理
MemoriOキューブを実際に積み重ねる。棚に並ぶ数が、その人の人生に残した節目の数になる。
デジタル
アプリに「声の年表」を形成し、日付・写真・メッセージ・音声を節目ごとに蓄積する。
接続
本体とアプリを紐づけ、キューブを開く体験と、人生全体を振り返るデジタル体験を共存させる。
4.3 現時点の製品デザイン方針
ブロック／キューブ型で、複数個を組み合わせ・積み重ねられる方向。
カラーは淡いホワイト、ピンク、ブルー、イエロー、グリーンの5色。
閉じた本体上面には4つの丸いスタッドを設け、積み上がる体験を視覚化する。
開いた本体では、スピーカーを蓋の裏面に配置し、下部には金属感のあるオルゴール機構を収める。
スマートフォンがなくても、蓋を開けるだけで声に出会えるシンプルな体験を重視する。

6. Brand Experience
MemoriOのブランド体験は、音声を保存する機能ではなく「言葉にできていなかった想いを声にするきっかけ」から始まります。
誰かを想う  →  声を残す  →  声を贈る  →  声に再会する  →  生活の中で何度も聞く  →  次の節目で積み重ねる
ブランド体験の基本原則
想いまで、贈る。 録音・招待・ギフトまでを「作る体験」にする。
離れていても、そばに。 本体を開くだけで声に出会える。スマホ操作を必須にしない。
人生と一緒に、積み重なる。 次の節目でキューブと声の年表が増えていく。

8. シーン別 Customer Journey
8.1 出産編
例：30歳夫婦。第一子の出産を1か月後に控えている。
購入前｜この瞬間を、ちゃんと残したい
SNSや出産準備の情報からMemoriOを知る。「産声や、今の家族の声を未来に残せる」という体験に惹かれる。20年後、子どもと一緒に聞く未来まで想像させる。
購入｜誰のために残すかを決める
誰のMemoriOか、出産予定日、贈る相手、テーマ、カラーを設定。「このMemoriOは、誰の人生に積み重なっていきますか？」という問いから、その子の最初の1ブロックとして認識してもらう。
録音｜出産前から家族の声を集める
父母・祖父母へ録音リンクを送り、「生まれてくるこの子に最初に伝えたいことは？」などの問いで今だから言える声を残す。出産当日は産声を人生最初の声として保存する。
贈る｜退院後に家族で完成させる
産声、両親、祖父母の声を一つにまとめる。子どものための1台だけでなく、祖父母へ孫の産声を贈るギフトとして複数台展開もできる。
開封｜初めて声に出会う
蓋を開けると孫の産声や家族の声が流れる。QRやスマホ操作より前に、物理的な「開く」行為そのものを感情のピークにする。
1年後｜2つ目を積む
1歳が近づくと「あの日から1年。今の声を残しませんか？」と通知。笑い声、初めての言葉、両親・祖父母のメッセージを新しいMemoriOに残し、Birthの上に1st Birthdayを積む。
8.2 カップル・記念日編
例：26歳女性。交際3周年の恋人へ、今年はいつもと違うものを贈りたい。
購入前｜モノだけでなく、今の気持ちを残したい
財布や香水ではなく「今の2人だから残せるもの」を探し、MemoriOに出会う。記念日・誕生日・遠距離・プロポーズが主な購入トリガー。
購入｜2人の記憶をつくり始める
Anniversaryとして交際開始日、周年、相手、カラー、写真などを登録。「何年後に一緒に聞きたいですか？」という未来起点の問いを置く。
録音｜普段言わないことを声にする
「3年間で一番覚えていることは？」「5年後の2人へ伝えたいことは？」などの問いから数本の声を残す。必要なら共通の友人からもメッセージを集める。
贈る｜記念日の最後に渡す
食事やデートの最後にMemoriOを渡す。商品説明をしすぎず、相手自身に蓋を開けてもらう。
開封｜恋人本人の声が流れる
「3年間ありがとう。普段こういうこと言わないけど…」と声が流れる。モノの中から本人が話しかけてくる体験をつくる。
1年後｜関係の歴史が積み上がる
4周年に前年の声を聞き返し、今の声を新しいキューブに残す。Anniversary → Proposal → Wedding → Familyへ、2人の関係そのものが積み上がる。
8.3 ウェディング編
例：29歳新婦・31歳新郎。結婚式をその日だけのイベントで終わらせたくない。
購入前｜自分たちらしい、残る演出を探す
式場やプランナーから「結婚式の日の声を残せる演出」として提案される。
購入｜誰の声を残すかを設計する
Weddingを選び、新郎→新婦、新婦→新郎、両親、ゲストなど収録対象を決める。1台にまとめるか、Couple / Parents / Friendsなど複数に分ける。
録音｜式前と当日に声を集める
招待状・Web招待状から録音リンクを送り、当日は会場にQRや専用端末を設置。「Voice Guestbook」として30秒の声を集める。
贈る｜披露宴演出または式後のギフト
新郎新婦から両親へ、またはプランナーから新郎新婦へ「今日の皆さんの声が入っています」と渡す。
開封｜目を閉じると式の日に戻れる
友人の笑い声、父親の緊張した声、母親の涙声、会場の空気を声で呼び戻す。動画とは違う没入感を価値にする。
1年後｜結婚記念日へ
「あの日から1年」と通知し、Wedding MemoriOを再生。その年の夫婦の声を1st Wedding Anniversaryとして追加する。出産すればCongratsへつながる。
8.4 学生編
例：高校3年生。部活引退・卒業で、仲間との今を残したい。
購入前｜卒業しても、この時間を残したい
写真や色紙とは違う記念品を探し、学割・グループ購入を使って共同購入する。
購入｜みんなでひとつを作る
Graduation / Clubを選び、部活名、卒業年、贈る相手を登録。代表者が録音リンクをグループLINEへ送る。
録音｜仲間の声を集める
「先輩との一番の思い出は？」「卒業後も覚えていてほしいことは？」などの問いで、後輩、同級生、先生の声を集める。
贈る｜卒業・引退の日
色紙や花束と一緒に渡し、その場で蓋を開けてもらう。
開封｜みんなで聞く
1人で聞くより、その場で笑ったり泣いたりする体験自体を新しい思い出にする。
1年後｜それぞれの人生へ
「卒業から1年」と通知。成人式、大学卒業、就職、恋愛、結婚と次のMemoriOへつながり、学生時代から人生の声を積み上げる。
8.5 家族・祖父母編
例：35歳女性。東京在住。遠方の65歳の母へ、5歳の娘の声を贈りたい。
購入前｜もっと孫を近くに感じてほしい
写真や動画はLINEで送れるが、日常で触れられる形にしたい。スマホ操作なしで孫の声を聞ける価値に惹かれる。
購入｜祖母のためのMemoriOを作る
Familyを選び、To / From、誕生日、カラーなどを登録する。
録音｜特別ではない日常の声も残す
「ばあば大好き」だけでなく、歌、幼稚園に行く声、笑い声、覚えた言葉、何気ない会話も残す。
贈る｜誕生日に配送
カードには「いつでも私たちの声を聞けるように。」と添える。
開封｜孫がそこにいるような感覚
蓋を開くと孫の声が流れる。スマホを探さず、棚に置いたMemoriOを開くだけ。Value「離れていても、そばに。」を直接体験させる。
1年後｜家族の成長が届く
次の誕生日に新しい声を追加。前年との声の変化を聞き比べる。将来的には祖父母から孫へも声を返し、世代をまたいで声を受け継ぐ。
9. Touchpoint Design
Touchpoint
設計方針
SNS / 広告
機能説明ではなく、祖父母が孫の声を聞く、卒業式で友人が声を聞くなど「声を贈る瞬間」を見せる。
Web / EC
「誰に、どんな声を残しますか？」から始め、出産・記念日・結婚・卒業・家族など用途起点で導く。
購入体験
誰に贈るか → どんな節目か → カラー → 日付・名前・メッセージを設定。購入時点から“作っている感覚”をつくる。
録音 Web / App
録音ボタンより先に質問を提示し、「今だから言える言葉」を引き出す。
声を集める Webリンク
LINEやメールで共有。受け取った人はアプリ不要でブラウザ録音。Wedding・Student・Familyで特に重要。
Package
説明書より前に本体に触れ、蓋を開けたくなる構成。開封そのものを儀式化する。
Device
蓋を開ける → 声が流れる。スマホがなくても声にアクセスできる。
App
本体のリモコンではなく「人生の声を積み重ねる場所」。縦に人生が積み上がる「声の年表」を中心にする。
1年後の再接触
販促ではなく「記憶の続きをつくる」通知。「あの日から1年。今の声も残しませんか？」
複数台になった時
物理キューブの積み重なりと、デジタル年表の積み重なりを一致させる。
10. ブランド運用の原則と次の設計テーマ
ブランドとして守ること
「録音機器」として売るのではなく、「声を贈る」という文化・体験として届ける。
「声」は人・感情・距離・時間をつなぐものとして扱い、過度にテクノロジー中心の表現にしない。
プロダクトは人生の節目ごとに増えることを前提にし、単発購入で終わる設計にしない。
若年層には学割・グループ購入など、文化への入口を用意する。
高齢者を含む受取人には、スマートフォン操作を前提としない「開けば聞ける」体験を守る。
物理キューブとデジタルの声の年表を同じ「人生の積み重ね」として一貫させる。
次に詳細設計するテーマ
アプリ情報設計：ホーム、声の年表、録音、招待、本体連携、次のMemoriO購入。
商品ライン設計：Birth / Anniversary / Wedding / Graduation / Family等の名称・仕様・価格差。
価格・学割・グループ購入・Wedding B2Bプラン。
ロゴ、タイポグラフィ、カラーパレット、写真・映像、コピーのTone &amp; Manner。
パッケージと開封体験。
セキュリティ・権利・音声データ保存・削除・継承ポリシー。
参考：初期事業プランでは、出産時の産声を蓋を開くアナログな行為で再生し、家族の歴史を未来につなぐ「心の装置」「音の遺伝子」を残す文化として構想されていました。本資料はその思想を引き継ぎつつ、現在のブランド議論に基づいて再定義したものです。
